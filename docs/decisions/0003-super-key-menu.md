# 0003 – Super-key app menu

- **Status:** accepted
- **Decision:**
  - Press and release Super → a menu (fuzzel) readable from the couch, listing the `apps` from `settings.yml`: websites, local services, commands.
  - Typed text that matches no entry opens as a website or a search.
  - Each entry opens as an app window. Choosing it again focuses the window already open.
- **See also:** labwc, which runs the menu ([0009](0009-labwc-custom-menu.md)).
